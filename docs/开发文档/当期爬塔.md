ActivityShikigami 开发者文档
适用于 OAS 项目（本地单机二开版）中的活动爬塔模块。
模块源自 OnmyojiAutoScript-mine 分支，已适配 OAS 旧版基础设施。

1. 概述
ActivityShikigami 是 OAS 项目中的一个任务模块，用于执行《阴阳师》各类爬塔活动（如孔雀国、伪神降临等）。该模块从 mine 分支复制而来，经过重构适配，使其能够在 OAS 项目的旧版 GeneralBattle 和 GameUi 基础设施上稳定运行。

支持的子模式：normal（常规爬塔）、fake_god（伪神活动）

入口任务：ScriptTask，默认执行 NormalClimbAct

设计目标：通用逻辑与活动描述分离，便于新增活动且不影响其他任务

2.2 核心模块说明

2.2.1 BaseAct（通用逻辑层）

位置：tasks/ActivityShikigami/base_act.py

职责：

活动循环控制（run() 方法）

门票检查（check_tickets_enough()）

御魂切换（switch_soul()）

阵容锁定（lock_team()）

战斗入口识别与调用（enter_battle() → run_general_battle()）

页面导航与状态管理

特性：

通过 descriptor 属性绑定具体的活动描述器

使用 pages 字典（由 create_event_pages 生成）管理活动页面

子类可重写 before_run() 实现模式切换等额外初始化

2.2.2 EventDescriptor（活动描述器）

位置：tasks/ActivityShikigami/descriptor.py

设计目的：将每个爬塔活动的差异化信息（入口图、主界面图、特殊页面钩子）抽象为数据对象，实现通用逻辑与活动描述的分离。

定义：

python
@dataclass
class EventDescriptor:
    event_id: str                      # 唯一标识
    name: str                          # 显示名称
    entry_button: RuleImage            # 庭院→活动入口按钮模板图
    main_page_check: RuleImage         # 活动主界面检测图
    main_page_enter_failure_hooks: list = None   # 进入主界面失败时的清理钩子
    on_setup_pages: Callable = None    # 注册额外页面的回调
    on_before_run: Callable = None     # 运行前的额外操作
预置描述器：

NORMAL_CLIMB：用于常规爬塔（如孔雀国）

FAKE_GOD_CLIMB：用于伪神活动，包含暗黑页等特殊页面注册

2.2.3 页面定义（page.py）

位置：tasks/ActivityShikigami/page.py

职责：定义活动相关的局部页面（不污染全局 GameUi/page.py）

核心函数：create_event_pages(desc: EventDescriptor) -> dict[str, Page]

根据描述器生成活动所需的所有页面对象（page_act, page_act_pass, page_act_ap, page_act_ap100, page_act_boss, page_main）

自动连接 page_main ↔ page_act 使用 desc.entry_button

page_act 的识别图使用 desc.main_page_check

依赖：复用 OAS 全局 Page 类、Matcher、Action 等

2.2.4 配置模型（config.py）
位置：tasks/ActivityShikigami/config.py

继承自 OAS 的 BaseTaskConfig，包含各子模式的战斗配置字段：

pass_battle_conf、ap_battle_conf、ap100_battle_conf、boss_battle_conf

每个字段为 GeneralBattleConfig 类型

配置通过 OASX 前端渲染，用户可调整战斗参数

3. 接入 OAS 项目的适配说明
3.1 背景
mine 分支对 GameUi 和 GeneralBattle 进行了架构级重构（基于 BattleContext + Page FSM），而 OAS 项目保留了旧版实现。直接复制 ActivityShikigami 会导致以下导入错误：

text
ImportError: cannot import name 'ExitMatcher' from 'tasks.Component.GeneralBattle.general_battle'
3.2 主要改动
文件	改动内容
config_general_battle.py	新增 continuous_battle, max_continuous, quick_exit, battle_timeout 字段（供 ActivityShikigami 兼容，旧版战斗循环不使用）
ActivityShikigami/page.py	修正导入：移除 page_battle、page_battle_prepare 等 mine 分支特有页面，改用 OAS 全局 Page、matcher、action
ActivityShikigami/base_act.py	移除 ExitMatcher、BattleContext、BattleAction 导入和对应覆写方法（_exit_matcher, _handle_result），战斗调用改为 run_general_battle(conf)（移除 battle_key 参数）
ActivityShikigami/activities/normal.py	移除 ExitMatcher 导入和 _exit_matcher 覆写
ActivityShikigami/script_task.py	移除 FakeGodAct 和 RichManAct 的导入（暂不启用）
3.3 兼容性处理
配置字段：使用 getattr(conf, 'field', default) 读取新增字段，避免 AttributeError

战斗循环：完全使用 OAS 旧版 GeneralBattle.battle_wait()，自动识别 I_WIN/I_FALSE/I_REWARD

页面导航：依赖 OAS Navigator 的 goto_page 机制，未知页面由导航器自行处理

4. 扩展开发指南
4.1 新增一个常规爬塔活动
准备素材：在 ActivityShikigamiAssets 中添加两张识别图：

庭院入口按钮（I_MAIN_GOTO_ACT 类似）

活动主界面检测图（I_TO_BATTLE_MAIN 类似）

注册描述器：在 descriptor.py 中定义一个新的 EventDescriptor 实例：

python
NEW_CLIMB = EventDescriptor(
    event_id="new_event",
    name="新活动名称",
    entry_button=ActivityShikigamiAssets.I_NEW_ENTRY,
    main_page_check=ActivityShikigamiAssets.I_NEW_MAIN,
    main_page_enter_failure_hooks=[...],  # 可选
)
在 script_task.py 中绑定：在 __init__ 中将 self.descriptor 设置为新描述器。

如果活动有特殊页面：实现 on_setup_pages 回调，在其中调用 self.navigator.add_page() 注册额外页面，并在 page.py 中定义这些页面（若需要）。

无需修改 base_act.py 或核心页面工厂。

4.2 新增特殊活动（如伪神）
若活动包含独特的页面交互（如暗黑页、答题等），可：

在 descriptor.py 中定义描述器，指定 on_setup_pages 回调

在回调中注册特殊页面，并建立页面连接

创建对应的活动类（继承自 BaseAct），在 before_run() 中绑定描述器，并实现特定逻辑（例如 fake_god.py 中的 _before_run 处理队伍选择）

5. 配置说明
5.1 GeneralBattleConfig 扩展字段
为了兼容 mine 分支，在 tasks/Component/GeneralBattle/config_general_battle.py 中新增了以下字段（OAS旧版战斗循环不使用，仅用于配置存储和前端显示）：

字段名	类型	默认值	说明
continuous_battle	bool	False	连续战斗开关（未使用）
max_continuous	int	0	最大连续次数（未使用）
quick_exit	bool	False	快速退出（未使用）
battle_timeout	float	120.0	单场超时（未使用）
这些字段由 OASX 自动渲染，用户可配置，但旧版 GeneralBattle 会忽略它们。

5.2 ActivityShikigami 专用配置
在 tasks/ActivityShikigami/config.py 中，ActivityShikigami 类包含四个战斗配置字段，分别对应不同模式：

pass_battle_conf：通行证模式

ap_battle_conf：AP消耗模式

boss_battle_conf：Boss挑战模式

每个字段均使用 GeneralBattleConfig 类型。

7. 注意事项与限制
FakeGodAct 和 RichManAct 暂未启用：在 script_task.py 中它们被注释，如需启用需先解决依赖（FakeGodAct 需要 DarkPage 等特殊页面，RichManAct 需要 DemonEncounter 和 Quiz 模块且涉及推送调用，OAS 已禁用推送）。

模块差异：本模块已与 mine 分支产生差异，后续若从 mine 分支合并更新，需再次适配。

不污染全局：所有活动相关页面定义均限定在 ActivityShikigami/page.py 内，不修改 tasks/GameUi/page.py。

战斗流程：依赖 OAS 旧版 GeneralBattle，不包含 mine 分支的 ExitMatcher 快速结束功能。

配置字段：新增字段仅用于兼容，不会改变旧版战斗行为。
